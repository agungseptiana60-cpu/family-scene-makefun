The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it fits the 1–280 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
